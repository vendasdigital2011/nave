# README - Upgrade CRM WhatsApp MVP

## Objetivo
CRM simples para abordagem de clientes de internet, focado inicialmente em upgrades de 50 Mega para 100 Mega.

## MVP
- Login
- Importação XLSX/CSV
- Cadastro de clientes
- Kanban (Frio, Morno, Quente, Vendido)
- Dashboard
- NPS
- Indicações
- Integração WhatsApp via Evolution API
- Atendimento 100% humano

## Stack
- Next.js 16
- TypeScript
- Tailwind
- Shadcn UI
- Supabase
- Vercel
- Evolution API

## Roadmap
1. Setup
2. Clientes
3. Kanban
4. Dashboard
5. WhatsApp
6. Homologação
